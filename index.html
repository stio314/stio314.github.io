toolbox:

  • enter fullscreen
  • draw on the canvas
  • fill closed areas with primary color
  • replace instances of the primary color with the secondary color
  • sample color at pointer position. left-click to set primary, right-click to set secondary
  • decrease brush size
  • increase brush size
  • undo

  • reset canvas pan/zoom

keyboard shortcuts:

  • b: brush tool
  • f: fill tool
  • r: color replace tool
  • i: colorpicker
  • [,]: decrease brush size, increase brush size
  • x: swap primary and secondary colors
  • -,+: zoom out, zoom in
  • ctrl+z: undo
  • ctrl+y,ctrl+shift+z: redo
  • space + drag: start panning

mouse:

  • middle click: start panning
  • mousewheel: zoom in / zoom out

touch:

  • two finger gesture: start panning / zooming
